# INTERVIESNE — Minimalist AI Resume Scanner & Interview Architect

A high-performance Next.js application that scans PDF resumes, detects technical competencies and seniority levels, matches eligible tech roles with skill-gap analysis, and synthesizes tailored interview questions with evaluation rubrics. Designed with a strict minimalist black-and-white, zero-slop UI.

---

## Features

- **PDF Resume Upload**: Drag-and-drop or select any `.pdf` resume file for server-side text extraction.
- **1-Click Sample Testing**: Instant testing with pre-loaded profiles (Senior Full-Stack, Lead AI/ML, Senior DevOps/SRE).
- **LLM & Semantic Engine**: Dual-mode extraction engine supporting external OpenAI API keys or an integrated 100% offline deterministic semantic extractor.
- **Comprehensive Job Role Catalog**: 14+ curated software engineering, systems, AI, cloud, security, and product roles with exact skill requirements and criteria.
- **Match Scoring & Skill Gap Analysis**: High-precision fit percentages, matching skill chips, missing skill-gap badges, and concise fit assessments.
- **Tailored Interview Preparation**: Role-specific technical, system architecture, gap-transition, and behavioral questions with expandable evaluation rubrics.
- **Monochrome Minimalist Interface**: Pure white background (`#FFFFFF`), solid black typography (`#000000`), subtle borders, zero marketing fluff or text slop.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Production Build & Start
```bash
npm run build
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
